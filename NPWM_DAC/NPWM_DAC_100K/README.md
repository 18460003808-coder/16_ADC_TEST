# NPWM_DAC 100 kHz

这是独立的低资源 100 kHz PWM 版本，不影响已有工程。

- 输入时钟：50 MHz
- PWM 频率：100 kHz
- PWM 周期：500 个系统时钟，即 10 us
- `pwm_duty`：0~100，表示整数百分比
- 每次有效 `trig` 上升沿将占空比加 1，并在 100 饱和
- `rst_pwm_n` 拉低后占空比立即回到 0
- 复位释放后必须先检测到 `trig` 为低，新的上升沿才会生效

为节省硬件资源，模块使用 5 时钟计数器和 100 个占空比时间槽，不使用乘法器
或除法器。使用 Quartus II 13.1 打开 `NPWM_DAC_100K.qpf`。工程沿用现有
板卡的输入和 PWM 输出引脚；`pwm_duty[6:0]` 未分配外部引脚。

ModelSim testbench 会遍历 0%~100%，每一级保持并检查 10 个完整 PWM 周期。
按项目约定，运行仿真前必须先取得用户许可。
