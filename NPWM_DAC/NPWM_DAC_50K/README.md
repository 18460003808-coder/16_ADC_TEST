# NPWM_DAC 50 kHz

这是独立的 50 kHz PWM 版本，不影响根目录下原有的 500 kHz 工程。

- 输入时钟：50 MHz
- PWM 频率：50 kHz（每周期 1000 个系统时钟）
- `pwm_duty`：0~100，表示整数百分比
- 每次有效 `trig` 上升沿将占空比加 1，并在 100 饱和
- `rst_pwm_n` 拉低后占空比立即回到 0
- 复位释放后，必须先检测到 `trig` 为低，新的上升沿才会生效

使用 Quartus II 13.1 打开 `NPWM_DAC_50K.qpf`。工程沿用原项目的板卡输入
和 PWM 输出引脚设置；`pwm_duty[6:0]` 未分配外部引脚。

ModelSim testbench 会遍历 0%~100%，每一级保持并检查 10 个完整 PWM 周期。
按项目约定，运行仿真前必须先取得用户许可。
