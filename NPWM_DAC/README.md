# NPWM_DAC

面向 EP4CE6E22C8N 的 500 kHz PWM 工程。工程输入时钟为 50 MHz，
占空比 `pwm_duty` 从 0 开始，每检测到一次 `trig` 上升沿增加 1，
达到 100 后保持不变。拉低 `rst_pwm_n` 可将占空比独立复位为 0。

## 接口

| 信号              | 方向 | 说明                           |
| ----------------- | ---- | ------------------------------ |
| `sysclk`        | 输入 | 50 MHz 系统时钟                |
| `rst_n`         | 输入 | 低有效全局复位                 |
| `trig`          | 输入 | 占空比递增触发信号，上升沿有效 |
| `rst_pwm_n`     | 输入 | 低有效占空比复位               |
| `pwm_out`       | 输出 | 500 kHz PWM 波形               |
| `pwm_duty[6:0]` | 输出 | 当前占空比，范围 0~100         |

`trig` 经过两级寄存器同步，因此从外部上升沿到 `pwm_duty` 更新存在同步延迟。

## 打开工程

使用 Quartus II 13.1 打开根目录下的 `NPWM_DAC.qpf`。板卡器件完整订货号为
EP4CE6E22C8N；Quartus 器件字段按工具识别格式设置为 Cyclone IV E
EP4CE6E22C8（末尾 `N` 为订货后缀，不写入工程器件字段）。由于需求未提供
板卡原理图或引脚表，工程未设置物理引脚；上板前需要根据实际板卡补充引脚约束。

## ModelSim 仿真

自检 testbench 位于 `sim/tb_npwm_dac.v`，脚本位于 `sim/run.do`。仿真会依次
遍历 0%~100% 的全部占空比。每次 `trig` 更新占空比后，testbench 会先对齐
到下一个 PWM 周期起点，再让该占空比持续并检查 10 个完整 PWM 周期，之后
才发送下一次 `trig`。相邻触发间隔约 22 us，总仿真时长约 2.2 ms。
按需求约定，执行任何 ModelSim 仿真前必须先取得用户许可；本次交付未运行仿真。

取得许可后，可在 `sim` 目录执行：

```text
vsim -c -do run.do
```

仿真完成后，在 `sim` 目录执行以下命令可打开并查看保存的完整波形：

```text
vsim -do view_wave.do
```
