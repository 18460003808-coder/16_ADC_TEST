# NPWM_DAC Adjustable Frequency

这是独立的低资源、频率可调 PWM 工程，不影响已有的固定频率版本。

## 频率设置

输入 `period_count[12:0]` 表示一个 PWM 周期包含的 50 MHz 时钟数：

```text
PWM频率 = 50,000,000 / period_count
```

| period_count | PWM频率 |
| ---: | ---: |
| 100 | 500 kHz |
| 125 | 400 kHz |
| 200 | 250 kHz |
| 500 | 100 kHz |
| 1000 | 50 kHz |
| 2500 | 20 kHz |
| 5000 | 10 kHz |

小于 100 的输入按 100 处理，大于 5000 的输入按 5000 处理。频率设置在
完整 PWM 周期边界更新，不会截断正在输出的周期。

## 低资源实现

模块将一个周期划分为 100 个占空比时间槽，通过小型累加器分配每个时间槽，
不使用运行时乘法器或除法器。周期不能被 100 整除时，各时间槽最多相差一个
50 MHz 时钟，占空比误差也不超过一个系统时钟。

`period_count` 和 `pwm_duty` 默认用于连接 FPGA 内部逻辑，因此没有分配物理
引脚。其余板卡引脚沿用已有工程。使用 Quartus II 13.1 打开
`NPWM_DAC_ADJ.qpf`。

ModelSim testbench 会检查 500 kHz、50 kHz、10 kHz、上下限钳位、50% 占空比
以及复位防误触发。按项目约定，执行仿真前必须先取得用户许可。
