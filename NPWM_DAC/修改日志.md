# 修改日志

## 2026-09-19

- 新建 Quartus II 13.1 工程；完整订货号为 EP4CE6E22C8N，Quartus 器件字段按工具格式设置为 EP4CE6E22C8。
- 新建 50 MHz 输入、500 kHz 输出的 PWM 模块 `npwm_dac`。
- 实现 `trig` 两级同步和上升沿检测，占空比按次加 1 并在 100 饱和。
- 实现低有效全局复位 `rst_n` 和低有效占空比复位 `rst_pwm_n`。
- 新建 ModelSim 自检 testbench 与运行脚本；遵照需求，本次未运行仿真。
- 新建工程使用说明；因缺少板卡引脚资料，未添加物理引脚约束。
- 使用 Quartus II 13.1 完成全流程编译：0 个错误；时序满足 50 MHz 要求。
- 编译检查时确认 Quartus 不接受订货号末尾的 `N`，已将工程器件字段修正为工具识别的 `EP4CE6E22C8`。
- 经用户许可运行 ModelSim 10.1d 自检仿真；RTL 与 testbench 编译成功，并在 14910 ns 输出 `PASS: all PWM checks completed`。
- 将 ModelSim 自动生成的 `sim/modelsim.ini` 加入忽略规则。
- 按要求扩展 testbench：完整遍历 0%~100% 占空比，每一级连续保持并自动检查 3 个 PWM 周期。
- ModelSim 运行脚本增加全层级波形记录，并新增 `sim/view_wave.do` 波形查看脚本。
- 经用户许可完成扩展后的 ModelSim 仿真：总时间 808510 ns，0%~100% 每级 3 个 PWM 周期全部检查通过，并生成完整 `sim/vsim.wlf` 波形文件。
- 根据波形观察反馈延长 `trig` 间隔：占空比更新后先对齐完整 PWM 周期，每一级连续运行并检查 10 个周期，之后才允许下一次触发；修改后等待重新仿真许可。
- 修正 `rst_pwm_n` 释放后占空比误加到 1：复位时同步清除触发检测状态，并要求同步后的 `trig` 先回到低电平，之后才接受新的上升沿。
- testbench 增加复位期间及复位释放后 `trig` 持续为高的回归场景；尚未运行修改后的 ModelSim 仿真。
- 修正后的 RTL 已通过 Quartus II 13.1 全流程编译，0 个错误，50 MHz 时序满足要求。
- 新增独立 `NPWM_DAC_50K` 工程：50 MHz 输入、50 kHz PWM 输出，保留 0~100 占空比、触发递增、饱和及复位防误触发逻辑。
- 50 kHz 工程沿用现有板卡的 `sysclk`、复位、触发和 `pwm_out` 引脚，并新增独立 ModelSim testbench 与波形查看脚本；尚未运行仿真。
- `NPWM_DAC_50K` 已通过 Quartus II 13.1 全流程编译：0 个错误，50 MHz 时序满足要求，并生成 `NPWM_DAC_50K.sof`。

## 2026-09-20

- 新增独立 `NPWM_DAC_ADJ` 低资源可调频率工程，使用 `period_count[12:0]` 设置 100~5000 个系统时钟周期，对应约 500 kHz~10 kHz。
- 采用 100 时间槽相位累加方案，避免运行时乘法器和除法器；新频率仅在完整 PWM 周期边界生效。
- 沿用占空比 0~100、触发递增、100 饱和及复位防误触发行为，并新增独立 ModelSim testbench；尚未运行仿真。
- 首次 Quartus 综合确认约使用 111 个逻辑单元；随后显式修正相位余数赋值位宽，消除综合截断警告。
- `NPWM_DAC_ADJ` 已通过 Quartus II 13.1 全流程编译：0 个错误；布局后使用 109/6272 个逻辑单元（约 2%）、47 个寄存器、0 个嵌入式乘法器，50 MHz 时序满足要求，并生成 `NPWM_DAC_ADJ.sof`。
- 经用户许可完成 `NPWM_DAC_ADJ` ModelSim 仿真：500 kHz、50 kHz、10 kHz、频率范围钳位、50% 占空比及复位防误触发全部通过；仿真结束于 712250 ns，并生成完整波形文件。
- 新增独立 `NPWM_DAC_100K` 低资源固定频率工程：50 MHz 输入、100 kHz 输出，使用 5 时钟/时间槽和 100 个占空比时间槽，避免乘法器与除法器。
- 100 kHz 版本沿用现有板卡引脚、占空比递增/饱和及复位防误触发逻辑，并新增独立 ModelSim testbench；尚未运行仿真。
- `NPWM_DAC_100K` 已通过 Quartus II 13.1 全流程编译：0 个错误；布局后使用 39/6272 个逻辑单元（小于 1%）、23 个寄存器、0 个嵌入式乘法器，50 MHz 时序满足要求，并生成 `NPWM_DAC_100K.sof`。
