ADS7953 串口采集与上位机说明
===============================

一、硬件连接

开发板使用 CH340 实现 USB 转串口，FPGA 串口网络为：

    uart_rxd = PIN_P16
    uart_txd = PIN_P20

直接用 USB 线连接开发板和电脑即可，不要再外接 MAX232。首次使用需要安装 CH340
驱动。[来源: EP4CE30VER6.1D硬件用户手册.pdf, 17. USB转RS232接口, p.26]

二、串口参数

    波特率：115200
    数据位：8
    校验位：无
    停止位：1
    流控：无

三、通信协议

上位机发送一个字节 0x54（ASCII 字符 T），FPGA 在 ADC 空闲且上一帧已经发送完成时
产生一个 trig_internal 脉冲，启动一次 CH0～CH15 扫描。忙碌期间收到的 T 不排队。

扫描完成后 FPGA 返回 36 字节：

    字节0       A5，帧头
    字节1       5A，帧头
    字节2       20，负载长度32字节
    字节3～34   CH0～CH15原始码，每路2字节、小端序，高4位固定为0
    字节35      XOR校验：字节2～34逐字节异或

上位机按以下公式换算电压：

    millivolts = round(code * 5000 / 4096)

四、运行上位机

推荐直接双击：

    host/dist/ADS7953_0-5V.exe

该单文件程序不要求目标电脑安装 Python。若需要从源码运行或重新开发，再按下面方式
安装 Python 依赖：

电脑安装 Python 3 后，在工程根目录执行：

    python -m pip install -r host/requirements.txt
    python host/ads7953_serial_gui.py

在窗口中选择 CH340 对应的 COM 口，点击“连接”，再点击“触发一次采集”。收到完整帧
后，表格会显示 CH0～CH15 的十六进制原始码、毫伏值和伏特值。

触发前可以在“备注”栏输入本组数据的说明，并通过“选择…”设置 Excel 文件。每次成功
收到完整的16路数据后，程序向“采集记录_0-5V”工作表追加一行，内容包括采集时间、备注、
CH0～CH15毫伏值，不写入原始码；独立的工作表名称可避免与旧量程数据混在一起。写入时
请不要用 Excel 打开同一个文件，否则 Windows 可能因为文件被占用而拒绝保存。
