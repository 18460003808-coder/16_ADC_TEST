# ADS7953 芯片详细使用手册

> 适用器件：Texas Instruments ADS7953（12 位、16 通道、1 MSPS SAR ADC）  
> 依据文档：TI 数据手册 SLAS605C（2018-07 修订）  
> 约定：`DI15..DI0` 是主机经 SDI 写入的 16 位字；`DO15..DO0` 是从 SDO 读回的 16 位字。

## 1. 芯片简介

ADS7953 是一款 12 位、16 通道、最高 1 MSPS 的逐次逼近型 ADC，采用外部基准，内部包含采样保持和 16 选 1 模拟多路复用器。器件通过 SPI 兼容的 16 位全双工串行接口配置并输出数据，支持 Manual、Auto-1、Auto-2 三种通道排序模式。[来源: chip reference/ads7953.pdf, 5 Device Comparison Table, p.5; 7.6 Electrical Characteristics, p.12; 8.1 Overview, p.28]

### 1.1 主要参数

| 项目 | 参数 |
|---|---:|
| 分辨率 | 12 bit |
| 模拟输入 | CH0～CH15，共 16 路 |
| 最高吞吐率 | 1 MSPS（SCLK=20 MHz） |
| 串行时钟 | 最大 20 MHz |
| 转换时间 | 16 个 SCLK；20 MHz 时为 800 ns |
| 采集时间 | 325 ns（规定测试条件） |
| 模拟电源 `+VA` | 2.7～5.25 V |
| 数字接口电源 `+VBD` | 1.7 V～`+VA` |
| 外部基准 `VREF` | 2.0～3.0 V，典型 2.5 V |
| Range 1 | 0～VREF |
| Range 2 | 0～2×VREF，前提是 2×VREF≤+VA |
| 输出编码 | 12 位直二进制，MSB first |
| 工作温度 | −40～125 ℃ |

[来源: chip reference/ads7953.pdf, 7.3 Recommended Operating Conditions, p.10; 7.6 Electrical Characteristics, p.12-13; 7.9 Timing Requirements, p.17]

### 1.2 精度、动态性能和极限值

在 VREF=2.5 V、1 MSPS 等规定条件下，ADS7953SB 等级的 INL 典型值为 ±0.5 LSB、最大值为 ±1 LSB，DNL 典型值为 ±0.5 LSB、范围为 −0.99～+1 LSB，并保证 12 位无失码；ADS7953S 等级保证 11 位无失码。100 kHz 输入时，SNR 典型值为 71.7 dB，THD 典型值为 −82 dB。正常模式模拟电源电流随电源和工作状态变化，+VA=4.7～5.25 V、1 MSPS 时典型 2.3 mA、最大 3 mA。[来源: chip reference/ads7953.pdf, 7.6 Electrical Characteristics, p.12-13]

绝对最大额定值不是正常工作条件：+VA 对 AGND、+VBD 对 BDGND 的绝对范围为 −0.3～7 V；AINP 或 CHn 对 AGND 为 −0.3～`VA+0.3 V`；非电源引脚输入电流为 ±10 mA。设计必须遵守前表的推荐工作范围，不能以绝对最大值作为工作目标。[来源: chip reference/ads7953.pdf, 7.1 Absolute Maximum Ratings, p.10]

|---:|---|---|

| 3 | REFM | 基准地 |

[来源: chip reference/ads7953.pdf, 6 Pin Configuration and Functions, p.5-7, Pin Functions: TSSOP Packages]

VQFN-32 版本也提供 16 路输入和完整 SPI 接口，但只有 GPIO0。GPIO1～GPIO3 以及 Range、PD 复用引脚只存在于 TSSOP 封装。[来源: chip reference/ads7953.pdf, 6 Pin Configuration and Functions, p.8-9; 8.1 Overview, p.28]

### 2.2 MXO 与 AINP 必须连通

信号路径是 `CHn → 内部 MUX → MXO → 外部网络 → AINP → ADC`。必须采取以下一种方式：

1. 直接短接 MXO 与 AINP；
2. 在 MXO 与 AINP 之间放置公共缓冲器、PGA 或滤波网络。

如果二者未连通，ADC 无法得到所选通道的正确电压。[来源: chip reference/ads7953.pdf, 8.1 Overview, p.28; 9.1.1 Analog Input, p.46-47, Figure 60-61]

### 2.3 电源、基准和去耦

- `+VA` 为 2.7～5.25 V；`+VBD` 为 1.7 V～`+VA`，且 `+VA≥+VBD`。
- 每个电源引脚就近放置 1 μF 陶瓷电容。
- REFP 与 REFM 之间必须就近放置 10 μF 陶瓷电容。
- AGND、BDGND、AINM、REFM 应低阻连接到模拟地平面。
- 电容与芯片引脚之间走线应短、粗，不要插入过孔。

[来源: chip reference/ads7953.pdf, 8.3.1 Reference, p.29; 10 Power Supply Recommendations, p.51; 11.1 Layout Guidelines, p.52]

### 2.4 输入驱动能力

通道切换时，内部约 15 pF 采样电容携带的上一通道电荷会扰动新通道。MXO 直连 AINP 时，TI 的一般建议是通道源阻抗不高于 50 Ω；应用章节给出的 1 MSPS、12 位建立条件为 Range 1 下 `RSOURCE≤100 Ω`、Range 2 下 `RSOURCE≤250 Ω`。每通道增加约 150 pF 可减小瞬态扰动。使用 OPA192 一类公共缓冲器后，1 MSPS、12 位时两种量程可放宽到约 500 Ω。[来源: chip reference/ads7953.pdf, 9.1 Application Information, p.46; 9.2.1 Unbuffered Multiplexer Output, p.48; 9.2.2 OPA192 Buffered Multiplexer Output, p.50]

## 3. SPI 接口与流水线

### 3.1 一帧操作

每帧固定包含 16 个 SCLK：

1. CS 下降沿开始一帧，对已经建立好的通道采样并启动转换；
2. SDO 在转换期间输出结果，SDI 同时接收下一步命令；
3. ADS7953 在 SCLK 上升沿锁存 SDI；
4. 除首位 DO15 由 CS 下降沿推出外，其余 SDO 位在 SCLK 下降沿更新；主机宜在上升沿采样；
5. 必须发满 16 个时钟后才能拉高 CS；第 16 个下降沿结束转换并使 SDO 进入高阻。

[来源: chip reference/ads7953.pdf, 7.9 Timing Requirements, p.17-18, Figure 1-2; 8.1 Overview, p.28]

按常见 SPI 术语，可配置为空闲低、上升沿采样、下降沿更新，即接近 SPI Mode 0；工程上仍应以数据手册的边沿关系为最终判据。

### 3.2 关键时序

| 项目 | 要求 |
|---|---:|
| SCLK | ≤20 MHz，高、低电平各≥20 ns |
| CS 高电平 | ≥20 ns |
| SDO 三态到下次转换的安静时间 `tq` | ≥40 ns |
| CS 低到首个 SCLK 上升沿 | VBD=1.8/3/5 V 时分别≥8/6/4 ns |
| SDI 建立时间 | VBD=1.8/3/5 V 时分别≥2/3/4 ns |
| SDI 保持时间 | VBD=1.8/3/5 V 时分别≥12/10/6 ns |

[来源: chip reference/ads7953.pdf, 7.9 Timing Requirements, p.17]

### 3.3 返回字格式

正常地址输出方式（`DI4=0`）：

```text
DO15             DO12 DO11                         DO0
+--------------------+--------------------------------+
| 当前转换通道号[3:0] |       12 位转换结果[11:0]       |
+--------------------+--------------------------------+
```

若前一帧把 `DI4` 写成 1，高 4 位改为 GPIO3～GPIO0 状态，低 12 位仍为转换结果。[来源: chip reference/ads7953.pdf, 8.1 Overview, p.28; Table 1, p.33; Table 2, p.36; Table 5, p.40]

```c
uint8_t  channel = (rx_word >> 12) & 0x0F; // DI4=0 时有效
uint16_t code    = rx_word & 0x0FFF;
```

### 3.4 两帧流水线延迟

命令、MUX 切换和结果不在同一帧完成。Manual 模式下，Frame N 发送“选择 CH4”，Frame N+1 的第 2 个 SCLK 下降沿才把 MUX 切到 CH4，Frame N+2 的 CS 下降沿采样 CH4 并输出结果。因此手动通道命令到目标结果有两帧延迟；切入 Auto 模式时也必须丢弃过渡返回值或按返回通道号重新同步。[来源: chip reference/ads7953.pdf, 8.4.4 Operating in Manual Mode, p.32-33, Figure 50-51; 8.4.5, p.34-35; 8.4.6, p.38-39]

## 4. 模式控制字公共位

| 位 | 定义 |
|---|---|
| `DI15:12` | `0000` 继续；`0001` Manual；`0010` Auto-1；`0011` Auto-2；其他值进入编程寄存器 |
| `DI11` | 更新使能：1 更新低位控制，0 保留此前设置 |
| `DI10` | Auto 模式序列复位；Manual 模式下属于通道号 |
| `DI9:7` | Manual 通道号低 3 位；Auto 模式无关 |
| `DI6` | 0=Range 1；1=Range 2 |
| `DI5` | 0=正常；1=请求掉电 |
| `DI4` | 0=返回通道号；1=返回 GPIO 状态 |
| `DI3:0` | 写给被配置为输出的 GPIO3～GPIO0 |

`DI6:0`（Auto 模式为 `DI10:0`）只有在 `DI11=1` 时更新。不需要修改设置时可发送 `0x0000`。[来源: chip reference/ads7953.pdf, Table 1, p.33; Table 2, p.36; Table 5, p.40; Table 7, p.41]

## 5. Manual 手动模式

### 5.1 特点

Manual 适用于随机访问、重复采集单通道或完全由主控安排顺序的应用。上电或复位后器件默认处于 Manual 模式并选择 CH0；第一笔转换无效。[来源: chip reference/ads7953.pdf, 8.4.1, p.29; 8.4.3, p.30-31; 7.6, p.13]

### 5.2 控制字

```text
DI15:12 = 0001
DI11    = 1：更新 DI6:0
DI10:7  = 下一目标通道 0～15
DI6     = 量程
DI5     = 掉电
DI4     = SDO 高 4 位来源
DI3:0   = GPIO 输出值
```

[来源: chip reference/ads7953.pdf, 8.4.4, p.33, Table 1]

```c
uint16_t ads7953_manual_word(uint8_t ch, bool range2,
                             bool power_down, bool read_gpio,
                             uint8_t gpio_out)
{
    return 0x1800u |
           ((uint16_t)(ch & 0x0Fu) << 7) |
           ((uint16_t)range2 << 6) |
           ((uint16_t)power_down << 5) |
           ((uint16_t)read_gpio << 4) |
           (gpio_out & 0x0Fu);
}
```

选择 CH4、Range 2、正常工作、返回通道号的命令是 `0x1A40`。发送后继续产生两帧，并以 `DO15:12==4` 判断 CH4 结果到达。[来源: chip reference/ads7953.pdf, p.33, Figure 51 and Table 1]

已选好通道后，后续发送 `0x0000` 可连续采样该通道。[来源: chip reference/ads7953.pdf, 8.4.7, p.41, Table 7]

## 6. Auto-1 任意通道列表模式

### 6.1 特点

Auto-1 用 16 位位图任选参与扫描的通道，器件按通道号升序循环。例如 CH2、CH5、CH6 的结果顺序为 2→5→6→2……。上电或复位后 ADS7953 位图为 `0xFFFF`，即全部 16 路；位图保持到掉电、复位或重编程，退出再进入不会清除。[来源: chip reference/ads7953.pdf, 8.4.1, p.29-30; 8.4.5, p.35-37]

### 6.2 编程位图

```text
Frame 1: 0x8000          // 进入 Auto-1 编程序列
Frame 2: channel_bitmap  // bit n=1 扫 CHn，bit n=0 跳过 CHn
```

只扫描 CH2、CH5、CH6：

```text
Frame 1: 0x8000
Frame 2: 0x0064
```

编程需要两帧。编程期间 SDO 仍有效，器件继续原模式，但不能在这些编程帧中修改量程或写 GPIO。[来源: chip reference/ads7953.pdf, p.37, Figure 54 and Table 3-4]

不要使用全零位图；数据手册没有为“无有效通道”定义正常扫描序列。

### 6.3 进入和运行

```text
DI15:12 = 0010
DI11    = 1：更新 DI10:0
DI10    = 1：回到位图中最低有效通道；0：正常前进
DI9:7   = 无关
DI6:0   = 公共量程、掉电、GPIO 控制
```

以 Range 2 进入并重置序列：`0x2C40`。进入 Auto-1 后自动从最低有效通道开始，随后持续发送 `0x0000`。返回数据要按 `DO15:12` 分配到通道缓存。[来源: chip reference/ads7953.pdf, p.34-36, Figure 52-53 and Table 2; p.41, Table 7]

运行中可以重编程位图。若正在 Auto-1 中修改位图，器件寻找下一个有效通道；若要确定地从最低通道重启，应在编程后再发送 `DI10=1` 的 Auto-1 模式字。[来源: chip reference/ads7953.pdf, 8.4.5, p.35]

## 7. Auto-2 连续深度扫描模式

### 7.1 特点

Auto-2 用“最后通道号”定义扫描深度，固定按 CH0→CH1→…→Last Channel 循环。适合从 CH0 开始的连续通道块；要跳过通道时应使用 Auto-1。[来源: chip reference/ads7953.pdf, 8.4.1, p.30; 8.4.6, p.38-41]

### 7.2 编程最后通道

```text
DI15:12 = 1001
DI11:10 = 无关
DI9:6   = 最后通道号 0～15
DI5:0   = 无关
```

```c
uint16_t auto2_program = 0x9000u | ((last_channel & 0x0Fu) << 6);
```

全 16 路为 `0x93C0`；CH0～CH7 为 `0x91C0`。上电或复位后 ADS7953 默认 Last Channel=15。[来源: chip reference/ads7953.pdf, p.30; p.40-41, Figure 57 and Table 6]

### 7.3 进入和运行

```text
DI15:12 = 0011
DI11    = 1：更新 DI10:0
DI10    = 1：从 CH0 重启；0：正常递增
DI9:7   = 无关
DI6:0   = 公共量程、掉电、GPIO 控制
```

进入 Auto-2、从 CH0 重启并选择 Range 2 的命令是 `0x3C40`。全 16 路推荐序列：

```text
Frame 0: 0x93C0    // Last Channel=15
Frame 1: 0x3C40    // 进入 Auto-2，从 CH0 重启，Range 2
Frame 2+:0x0000    // 保持模式并连续扫描
```

进入 Auto-2 的下一帧才切换到 CH0，再下一帧返回完整 CH0 结果。接收端应丢弃配置阶段数据，直到返回通道号 0，再按 0～15 收集。进入 Auto-2 或在运行中重写 Auto-2 Program Register 都会使扫描从 CH0 重启。[来源: chip reference/ads7953.pdf, 8.4.6, p.38-41, Figure 55-57 and Table 5-6]

## 8. 模式选择总结

| 特性 | Manual | Auto-1 | Auto-2 |
|---|---|---|---|
| 通道定义 | 每帧指定 | 16 位任意通道位图 | 指定最后通道 |
| 顺序 | 主控决定 | 有效通道升序循环 | CH0～Last 升序循环 |
| 预编程 | 无 | 2 帧 | 1 帧 |
| 适用场景 | 随机访问、单通道 | 稀疏通道集合 | 从零开始的连续通道块 |
| 上电默认 | Manual、CH0 | `0xFFFF` | Last=15 |
| 进入模式 | 目标通道按流水切换 | 回到最低有效通道 | 回到 CH0 |

[来源: chip reference/ads7953.pdf, 8.4.1 Channel Sequencing Modes, p.29-30; 8.4.4-8.4.6, p.31-41]

## 9. Continue 连续运行命令

当 `DI15:12=0000` 时，器件保持当前模式和全部设置，并忽略 `DI11:0`：

- Manual：继续转换最后选择的通道；
- Auto-1：按位图前进；
- Auto-2：从 CH0 到 Last Channel 前进。

因此，初始化后没有量程/GPIO变更时，可把 SDI 固定为低并持续传输 `0x0000`。[来源: chip reference/ads7953.pdf, 8.4.7 Continued Operation in a Selected Mode, p.41, Table 7]

## 10. 数字码与电压换算

ADS7953 输出 12 位直二进制：

```text
Range 1: FS=VREF,   LSB=VREF/4096
Range 2: FS=2×VREF, LSB=2×VREF/4096
Vin_ideal=Code×FS/4096
```

`0xFFF` 对应 `FS−1 LSB`，`0x800` 对应半量程，`0x000` 对应 0 V。[来源: chip reference/ads7953.pdf, 8.5.1 Digital Output, p.41, Table 8]

VREF=2.500 V 时：

| 量程 | 理想范围 | 1 LSB | 毫伏换算 |
|---|---:|---:|---|
| Range 1 | 0～2.500 V | 0.6103516 mV | `code×2500/4096` |
| Range 2 | 0～5.000 V | 1.2207031 mV | `code×5000/4096` |

```c
uint32_t millivolts = ((uint32_t)code * full_scale_mV + 2048u) >> 12;
```

Range 2 只有在 `2×VREF≤+VA` 时才满足规定。VREF=2.5 V、+VA=3.3 V 时，不能把 Range 2 当作合规的 0～5 V 量程。[来源: chip reference/ads7953.pdf, 7.6 Electrical Characteristics, p.12]

## 11. GPIO 模式

### 11.1 GPIO Program Register

发送 `DI15:12=0100` 选择 GPIO Program Register：

| 位 | 作用 |
|---|---|
| `DI11:10` | 必须为 `00` |
| `DI9` | 1：下一 CS 帧复位器件和全部寄存器；0：正常 |
| `DI8` | 1：GPIO3 复用为低有效 PD（仅 TSSOP） |
| `DI7` | 1：GPIO2 复用为 Range 输入（仅 TSSOP） |
| `DI6:4` | GPIO0/GPIO1 告警功能选择 |
| `DI3:0` | 未复用 GPIO3～GPIO0：1=GPO，0=GPI |

[来源: chip reference/ads7953.pdf, 8.5.2 GPIO Registers, p.42-43, Table 11]

告警复用值：

| `DI6:4` | 功能 |
|---|---|
| `000` | GPIO1、GPIO0 为普通 I/O |
| `xx1` | GPIO0 输出高或低告警的合并结果 |
| `010` | GPIO0 输出高告警 |
| `100` | GPIO1 输出低告警，GPIO0 普通 I/O（仅 TSSOP） |
| `110` | GPIO1 输出低告警、GPIO0 输出高告警（仅 TSSOP） |

[来源: chip reference/ads7953.pdf, p.43, Table 11]

TSSOP 封装、四个 GPIO 均保持普通输入时，软件复位命令可写成 `0x4200`：高 4 位选择 GPIO 寄存器，DI9=1。VQFN 封装按表 11 要求应把不存在的 GPIO3～GPIO1 方向位写 1，例如 GPIO0 保持输入时使用 `0x420E`。复位在下一 CS 帧发生，之后返回 Manual/CH0 等复位状态，第一笔转换应丢弃。[来源: chip reference/ads7953.pdf, p.43, Table 11; 7.6 Electrical Characteristics, p.13]

### 11.2 GPIO 读写

- GPO 值通过普通模式控制字的 `DI3:0` 写入，在下一 CS 下降沿刷新；
- GPI 状态在 CS 下降沿锁存；上一帧令 `DI4=1` 后，通过本帧 `DO15:12` 输出；
- `DI4=1` 时返回字不含通道号，软件必须自行维护通道归属。

[来源: chip reference/ads7953.pdf, 8.1 Overview, p.28; 8.5.2 GPIO Registers, p.42]

GPIO2 可在 TSSOP 中复用为 Range 输入：高电平选 Range 2，低电平选 Range 1。QFN 没有 GPIO2，相关配置必须保持 0。[来源: chip reference/ads7953.pdf, 6 Pin Configuration and Functions, p.7; p.43, Table 11]

## 12. 告警阈值编程模式

### 12.1 通道分组

每个通道有高、低两个阈值。ADS7953 分成四组：

| 组号 `bb` | 通道 | 进入帧 |
|---:|---|---:|
| 0 | CH0～CH3 | `0xC000` |
| 1 | CH4～CH7 | `0xD000` |
| 2 | CH8～CH11 | `0xE000` |
| 3 | CH12～CH15 | `0xF000` |

[来源: chip reference/ads7953.pdf, 8.5.3 Alarm Thresholds for GPIO Pins, p.43-45, Table 12-13]

完整编程一组最多需要 9 帧：第 1 帧选组，后续最多 8 帧写四个通道的高、低阈值。也可以少写，在最后一个阈值帧设置退出位。[来源: chip reference/ads7953.pdf, p.43-45, Figure 59 and Table 13]

### 12.2 阈值帧位定义

```text
DI15:14 = cc：组内通道号；完整通道号为 bbcc
DI13    = 1：高阈值；0：低阈值
DI12    = 1：本帧后退出；0：继续告警编程
DI11:10 = 无关
DI9:0   = 10 位阈值
```

ADS7953 用 12 位结果的高 10 位 `Code[11:2]` 比较：结果高于高阈值触发高告警，低于低阈值触发低告警。高阈值复位为全 1，低阈值复位为全 0。[来源: chip reference/ads7953.pdf, p.45, Table 13]

```text
threshold10 ≈ Vin_threshold×1024/FS
比较步长 = FS/1024 = 4 个 12-bit LSB
```

### 12.3 示例：CH0 的 1 V～3 V 窗口

假设 VREF=2.5 V、Range 2、FS=5 V：

```text
低阈值 ≈ round(1/5×1024)=205=0x0CD
高阈值 ≈ round(3/5×1024)=614=0x266

Frame 1: 0xC000   // 选择组 0
Frame 2: 0x00CD   // CH0 低阈值，继续
Frame 3: 0x3266   // CH0 高阈值，DI12=1，写后退出
```

之后还要用 GPIO Program Register 配置告警输出引脚；只写阈值不会自动改变 GPIO 复用。[来源: chip reference/ads7953.pdf, p.43-45, Table 11-13]

越限时，告警可在该转换帧第 12 个 SCLK 下降沿置位，并在下一帧第 10 个下降沿复位。[来源: chip reference/ads7953.pdf, 8.1 Overview, p.28]

## 13. 掉电与唤醒模式

### 13.1 通过串行命令掉电

在当前模式控制字中令 `DI11=1、DI5=1`。器件在下一数据帧第 16 个 SCLK 下降沿掉电。若 DI11 不置 1，DI5 不会更新。[来源: chip reference/ads7953.pdf, 8.3.2 Power Saving, p.29; Table 1, p.33; Table 2, p.36; Table 5, p.40]

### 13.2 通过 GPIO3/PD 掉电

TSSOP 可先设置 GPIO Program Register 的 `DI8=1`，把 GPIO3 配置为异步、低有效 PD。GPIO3 拉低后器件立即掉电。QFN 不支持此引脚方式。[来源: chip reference/ads7953.pdf, 8.3.2, p.29; p.43, Table 11]

### 13.3 唤醒

当 GPIO3/PD 为高，CS 下降沿配合 `DI5=0` 的模式控制使器件重新上电。典型上电时间为 1 μs；上电或复位后的第一笔转换无效，必须丢弃。掉电态典型电源电流为 1 μA。[来源: chip reference/ads7953.pdf, 7.6 Electrical Characteristics, p.13; 8.3.2, p.29]

## 14. 上电、复位与初始化

### 14.1 默认状态

- Manual 模式，CH0；
- Range 1；
- Auto-1 位图 `0xFFFF`；
- Auto-2 Last Channel=15；
- 第一帧 SDO 无效。

[来源: chip reference/ads7953.pdf, 8.4.1-8.4.3, p.29-31; Table 1-7, p.33-41]

### 14.2 推荐 Auto-2 全通道初始化

```text
1. 等待 +VA、+VBD、VREF 稳定，并覆盖至少 1 μs 芯片上电时间。
2. 完整传输一帧，丢弃返回值。
3. 发送 0x93C0：Last Channel=15。
4. 发送 0x3C40：进入 Auto-2，从 CH0 重启，Range 2。
5. 连续发送 0x0000。
6. 丢弃过渡字，直到返回通道号 0。
7. 按 0～15 收集；收到 CH15 表示一轮结束。
```

使用 Range 1 时把步骤 4 改为 `0x3C00`。外部电源和基准源若需要更长稳定时间，应采用其中更大的等待值。[来源: chip reference/ads7953.pdf, 7.6, p.13; 8.4.6, p.38-41]

### 14.3 推荐 Auto-1 稀疏列表初始化

扫描 CH0、CH3、CH8、CH15：

```text
Frame A: 0x8000
Frame B: 0x8109   // bit15 | bit8 | bit3 | bit0
Frame C: 0x2C40   // Auto-1，从最低有效通道重启，Range 2
Frame D+:0x0000
```

进入后按返回通道号识别 `0→3→8→15→0`，不要把配置帧返回值误认为新序列。[来源: chip reference/ads7953.pdf, 8.4.5, p.34-37]

## 15. 主控实现参考

### 15.1 16 位传输伪代码

```c
uint16_t ads7953_transfer16(uint16_t tx)
{
    uint16_t rx = 0;

    CS_LOW();
    delay_ns_at_least(8);       // 根据实际 VBD 满足 tsu1

    for (int bit = 15; bit >= 0; --bit) {
        SCLK_LOW();
        SDI_WRITE((tx >> bit) & 1u);
        delay_half_sclk();

        SCLK_HIGH();            // ADC 锁存 SDI，主机采样 SDO
        rx = (uint16_t)((rx << 1) | SDO_READ());
        delay_half_sclk();
    }

    SCLK_LOW();
    CS_HIGH();
    delay_ns_at_least(100);     // 保守覆盖 SDO 三态延迟、tq 和 CS 高宽
    return rx;
}
```

硬件 SPI 可使用 16 位、MSB first、空闲低/上升沿采样配置，时钟不得超过 20 MHz。示例采用 100 ns 帧间隔，是为了保守覆盖第 16 个时钟后的 SDO 三态延迟、至少 40 ns 的安静时间及至少 20 ns 的 CS 高宽；若要压缩间隔，应按实际 VBD 对这些时间逐项核算。[来源: chip reference/ads7953.pdf, 7.9 Timing Requirements, p.17-18; 8.1 Overview, p.28]

### 15.2 自动扫描接收策略

```c
if (!synced) {
    if (channel == first_expected_channel) {
        synced = true;
        store(channel, code);
        expected = next_enabled_channel(channel);
    }
} else if (channel == expected) {
    store(channel, code);
    expected = next_enabled_channel(channel);
} else {
    // 可能是过渡帧、漏帧或 SPI 错位：等待下轮首通道
    synced = false;
}
```

该方法利用返回通道号吸收模式切换的流水线过渡，并检测漏帧。若 `DI4=1`，高 4 位是 GPIO，不能再用它同步通道。[来源: chip reference/ads7953.pdf, 8.1 Overview, p.28; Table 1, p.33; Table 2, p.36; Table 5, p.40]

### 15.3 吞吐率估算

```text
frame_rate ≈ 1 / (16/fSCLK + t_gap)
```

20 MHz 且满足最小时序时，额定最高吞吐率是 1 MSPS。降低 SCLK、增加帧间隔会降低实际吞吐率；高源阻抗场合降低采样率有助于增加建立裕量。[来源: chip reference/ads7953.pdf, 7.6, p.12; 7.9, p.17; 9.2, p.48-51]

## 16. PCB 布局要点

- 10 μF 基准去耦紧贴 REFP/REFM；
- 每个 +VA、+VBD 引脚分别就近放 1 μF；
- 芯片下铺铜连接 AGND、BDGND、AINM、REFM，并用至少四个过孔接模拟地平面；
- SPI 和其他高速数字线远离模拟输入、MXO/AINP、基准网络；
- 去耦电容与对应芯片引脚之间不要放过孔；
- MXO/AINP 间使用运放时，要保证大信号摆率和小信号建立满足约 600 ns 的 MUX 建立窗口。

[来源: chip reference/ads7953.pdf, 9.2.2.2 Detailed Design Procedure, p.50; 11.1 Layout Guidelines, p.52]

## 17. 常见故障排查

### 17.1 所有通道数据异常或相似

先检查 MXO 是否通过短接、缓冲器或滤波器连到 AINP，再检查 AINM、REFM、AGND。MXO/AINP 未连通时，SPI 正确也无法读到正确电压。[来源: chip reference/ads7953.pdf, 9.1.1 Analog Input, p.46-47]

### 17.2 通道号错一位或两位

通常是忽略了流水线。Manual 命令的目标结果在 N+2 帧返回，切入自动模式也有过渡帧。应以返回通道号同步，不要按发送命令的帧号归属数据。[来源: chip reference/ads7953.pdf, p.33 Figure 51; p.35 Figure 53; p.39 Figure 56]

### 17.3 高电压端失真或提前满量程

检查 Range 和 +VA。Range 2 要求 `2×VREF≤+VA`，输入还必须处于规定的输入范围。[来源: chip reference/ads7953.pdf, 7.6 Electrical Characteristics, p.12]

### 17.4 通道切换后第一点跳变

这是源阻抗过高或建立时间不足的典型表现。可降低源阻抗、每通道增加约 150 pF、降低吞吐率，或在 MXO/AINP 间加入合适缓冲器。[来源: chip reference/ads7953.pdf, 9.1, p.46; 9.2, p.48-51]

### 17.5 SDO 高 4 位不像通道号

检查上一帧的 `DI4`。DI4=1 时高 4 位是 GPIO3～GPIO0，不是通道地址。[来源: chip reference/ads7953.pdf, p.33 Table 1; p.36 Table 2; p.40 Table 5]

### 17.6 自动扫描反复回到首通道

Auto 控制字的 DI10=1 会复位通道计数器；进入 Auto-2 或重写 Auto-2 Program Register 也会回到 CH0。连续采集应发送 `0x0000`，不要每帧重复进入命令。[来源: chip reference/ads7953.pdf, p.36 Table 2; p.39-41 Figure 56 and Table 5-7]

### 17.7 上电或唤醒后第一点错误

这是器件规定行为：上电或复位后的第一笔转换无效。初始化、软件复位和唤醒后都应丢弃首笔并重新同步。[来源: chip reference/ads7953.pdf, 7.6, p.13; 8.4.3, p.30-31]

## 19. 本项目中的应用

当前工程的 `rtl/ads7953_16ch_reader.v` 使用：

```verilog
localparam [15:0] CMD_AUTO2_PROGRAM = 16'h93C0;
localparam [15:0] CMD_AUTO2_ENTER   = 16'h3C40;
localparam [15:0] CMD_CONTINUE      = 16'h0000;
```

流程是设置 Last=15，以 Range 2 从 CH0 进入 Auto-2，随后连续发零，并用返回高 4 位的 0～15 做同步和存储。这与数据手册 Auto-2 寄存器和流水时序一致。[来源: rtl/ads7953_16ch_reader.v; chip reference/ads7953.pdf, 8.4.6, p.38-41]

本项目板级原理图使用 ADS7953SBDBTR、+5 V 模拟电源、+3.3 V 数字接口电源、+2.5 V 基准，对应 Range 2 的理想 0～5 V 范围。实际硬件必须确认 MXO→AINP、REFM 接地，以及 REFP/REFM 间的 10 μF 就近去耦。[来源: 电路原理图.pdf, p.1; chip reference/ads7953.pdf, 8.3.1, p.29; 9.1.1, p.46]

## 20. 设计检查清单

- [ ] +VA 为 2.7～5.25 V，+VBD 为 1.7 V～+VA；
- [ ] VREF 为 2.0～3.0 V，Range 2 时 2×VREF≤+VA；
- [ ] 每个电源脚有就近 1 μF，REFP/REFM 有就近 10 μF；
- [ ] MXO 已接 AINP，或中间有完整信号调理路径；
- [ ] 源阻抗、通道电容、帧率满足 12 位建立要求；
- [ ] SPI 每帧恰好 16 个时钟，MSB first，SCLK≤20 MHz；
- [ ] CS 高电平≥20 ns、SDO 三态后的安静时间≥40 ns，并已计入 SDO 三态延迟；
- [ ] 上电、复位、唤醒、模式切换后的无效/过渡结果已丢弃；
- [ ] 用返回通道号而不是发送帧号归属数据；
- [ ] 连续扫描发送 `0x0000`，没有反复置 DI10；
- [ ] DI4=1 时，软件知道高 4 位已经变成 GPIO；
- [ ] 告警阈值、引脚复用和 10 位阈值量化均已校验。
