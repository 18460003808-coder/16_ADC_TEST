# 共用 SCLK、SDI、SDO，独立 CS 的硬件连接

## 1. 总线结构

ADS7953 的 `CS` 是低有效输入，`SCLK/SDI` 是数字输入，`SDO` 是数字输出。[来源: ADS7953_0-5V/chip reference/ads7953.pdf, 6 Pin Configuration and Functions, p.7]

| FPGA信号 | 底板连接 | ADC板CN1 | 数量 |
|---|---|---:|---:|
| `adc_sclk` | 经U1缓冲为4条同源支路，每支路接5块板 | 8 | 1个FPGA输出 |
| `adc_sdi` | 经U1缓冲为4条同源支路，每支路接5块板 | 4 | 1个FPGA输出 |
| `adc_sdo` | 20块板的SDO并成一根总线，只允许被选中的板驱动 | 5 | 1个FPGA输入 |
| `adc_cs_n[0]`～`[19]` | 每块板一根独立片选 | 3 | 20个FPGA输出 |
| GND | FPGA、缓冲器、20块板公共地 | 2 | 公共回流 |
| 板卡电源 | 外部DC 5 V分配到每块板 | 1 | CN1-1 |

板卡CN1的图面定义为：1=`VCC`、2=`AGND`、3=`CS#`、4=`SDI`、5=`SDO`、6=`GPIO0`、7=`GPIO1`、8=`SCLK`、9=`GPIO2`、10=`GPIO3`。[来源: ADS7953_0-5V/电路原理图.pdf, p.1]

## 2. 推荐底板电路

### U1：SCLK/SDI扇出

使用一片 `SN74LVC244APW`（TSSOP-20）或同等74LVC244，VCC必须接3.3 V，不能接板卡的外部5 V：

- 1A1（2脚）、1A2（4脚）、1A3（6脚）、1A4（8脚）全部连接FPGA `adc_sclk`；1Y1（18脚）、1Y2（16脚）、1Y3（14脚）、1Y4（12脚）分别驱动4组SCLK，每组5块板。
- 2A1（11脚）、2A2（13脚）、2A3（15脚）、2A4（17脚）全部连接FPGA `adc_sdi`；2Y1（9脚）、2Y2（7脚）、2Y3（5脚）、2Y4（3脚）分别驱动4组SDI，每组5块板。
- 1OE（1脚）和2OE（19脚）是低有效输出使能，本项目直接接GND，使缓冲输出始终有效。
- VCC（20脚）接3.3 V，GND（10脚）接公共数字地。
- FPGA侧的公共SCLK输入和公共SDI输入各加10 kΩ下拉，避免FPGA配置期间74LVC244输入悬空、输出支路误跳变。
- U1电源脚旁放置100 nF陶瓷电容，附近增加1 µF组级去耦。
- 每个Y输出到分组主干之间预留串阻位置，初始装0 Ω；根据示波器结果调整为22～33 Ω。

这样在逻辑上仍是一个SCLK和一个SDI，但避免单个FPGA引脚直接驱动20块板及20条支路。

### 20路CS

每根CS单独从FPGA连接到对应板卡：

```text
adc_cs_n[0]  -> Board 0  CN1-3
adc_cs_n[1]  -> Board 1  CN1-3
...
adc_cs_n[19] -> Board 19 CN1-3
```

每根CS在底板连接器附近加4.7～10 kΩ上拉至3.3 V，确保FPGA上电配置、复位或引脚高阻期间所有ADC均未选中。每根CS另预留0/22/33 Ω串阻焊位，初始可装0 Ω。

### 共用SDO

20块板的CN1-5连接到同一条SDO主干，再进入FPGA `adc_sdo`。现有板卡在每颗ADS7953的SDO与连接器之间已经串联33 Ω，因此每个潜在驱动源都有隔离电阻。[来源: ADS7953_0-5V/电路原理图.pdf, p.1]

FPGA端建议：

- 加10 kΩ下拉，使所有CS为高时总线保持确定电平。
- 预留 `74LVC1G17` 接收缓冲位置；短底板可先用0 Ω旁路，波形差时再安装。
- 测试点放在FPGA接收端，而不是只测某块ADC板端。
- PCB采用一条连续主干，板卡插槽产生的支线尽量短；不要把20条长线汇聚成星形。

## 3. CS切换规则

共享SDO的成立条件是任意时刻最多只有一个CS为低。ADS7953在CS变高后将SDO切换为三态；3 V数字接口条件下，`CS high -> SDO three-state` 最大延迟为21 ns。[来源: ADS7953_0-5V/chip reference/ads7953.pdf, 7.9 Timing Requirements, p.17, td4]

底层控制必须采用先断后通：

```text
1. 停止SCLK，保持低电平
2. 当前板CS拉高
3. 所有20路CS保持高至少100 ns
4. 目标板CS拉低
5. 等待建立时间后开始16个SCLK
```

手册规定CS高脉宽至少20 ns、总线三态至下一次转换需要至少40 ns静默时间；选用100 ns可同时覆盖这两个要求并留出PCB延迟余量。[来源: ADS7953_0-5V/chip reference/ads7953.pdf, 7.9 Timing Requirements, p.17, tq/tw1]

建议在硬件或FPGA逻辑中加入“one-hot-or-zero”保护：允许所有CS为高，但禁止同时出现两路低电平。

## 4. 时钟与电平

ADS7953推荐 `+VBD=1.7 V～+VA`，SCLK最高20 MHz；现有板卡图面使用3.3 V数字接口，因此FPGA对应I/O Bank也必须使用3.3 V供电和3.3-V LVTTL标准。[来源: ADS7953_0-5V/chip reference/ads7953.pdf, 7.3 Recommended Operating Conditions, p.10] [来源: ADS7953_0-5V/电路原理图.pdf, p.1]

3 V数字接口下：

- SCLK高、低脉宽分别至少20 ns。
- SDI在SCLK上升沿前至少建立3 ns，上升沿后至少保持10 ns。
- SDO在SCLK下降沿后最长27 ns有效，FPGA应在下一上升沿采样。

[来源: ADS7953_0-5V/chip reference/ads7953.pdf, 7.9 Timing Requirements, p.17]

20板总线初次联调建议从2～5 MHz开始。10 MHz能否可靠运行，应以最远插槽处的SCLK、SDI和FPGA端SDO实测波形为准。

## 6. 外部5 V配电

已确认每块ADC板的CN1-1由外部DC 5 V供电。5 V应采用星形或分组配电，不建议从第一块板串接到第二块板再逐块级联；所有板卡CN1-2与FPGA地必须共地。

电源额定电流按下面方式确定：

```text
电源额定电流 >= 20 × 单块板最大实测电流 × 1.5
```

建议先让一块板以目标采样速率连续工作，测量CN1-1的最大电流，再确定DC电源、主电源线、连接器和分组保险丝规格。原理图中的3.3 V数字接口和2.5 V参考源如何由5 V产生仍应在实物或完整网表上确认。[来源: ADS7953_0-5V/电路原理图.pdf, p.1]

## 7. 上板验证顺序

1. 不插ADC板，确认20根CS上电后均为高。
2. 插1块板，确认共享SDO可正常读取。
3. 插2块板，故意只选其中一块，检查另一块SDO确实处于高阻且无总线冲突。
4. 扩展到同组5块，再逐组增加至20块。
5. 在最远插槽测量SCLK/SDI，在FPGA端测量SDO，逐步从2 MHz提高到5 MHz、10 MHz。
6. 连续轮询20块板，确认任何时刻只有一路CS为低，并检查SDO切换间隔。
