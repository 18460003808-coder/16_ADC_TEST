# ADS7953 20板级联硬件设计日志

## 2026-09-07：硬件方案与原理图确认

### 总体方案

- FPGA控制20块ADS7953板卡，板卡依次采样，不要求同时采样。
- 20块板共用一组逻辑SCLK、SDI和三态SDO。
- 每块板使用独立CS，共20路CS。
- FPGA共占用23个GPIO：`SCLK + SDI + SDO + CS[19:0]`。
- 任意时刻只允许一路CS为低，其余CS必须保持高电平。

### 电源与地

- 20块ADS7953板的CN1-1由级联板外部DC 5V供电。
- 级联板使用ADP150AUJZ-3.3产生3.3V，仅供74LVC244、上拉/下拉网络等逻辑电路使用。
- 74LVC244的VCC（pin 20）和去耦电容C1接`+3.3V`，不能接5V。
- 所有子板CN1-2、级联板、FPGA接口共用同一个GND平面，不再通过小封装0Ω电阻汇总回流。
- FPGA板插接接口为J11。由于级联板使用独立5V电源，U1-1和U1-40均设为NC，避免与J11的5V并联或反向灌电；U1-5接GND。
- J11属于FPGA Bank6，必须保持`VCCIO6=3.3V`；确认FPGA板R53为默认3.3V配置。

### 74LVC244连接

- U2 pin 1（`/1OE`）和pin 19（`/2OE`）接GND，缓冲器始终使能。
- U2 pin 10接GND，pin 20接3.3V；pin 20附近放置100nF去耦电容。
- FPGA_SCLK同时连接U2 pin 2、4、6、8。
- U2 pin 18、16、14、12分别输出SCLK0、SCLK1、SCLK2、SCLK3。
- FPGA_SDI同时连接U2 pin 11、13、15、17。
- U2 pin 9、7、5、3分别输出SDI0、SDI1、SDI2、SDI3。
- 缓冲器输入可以并联，输出之间禁止并联。
- SCLK0/SDI0连接板0～4，SCLK1/SDI1连接板5～9，SCLK2/SDI2连接板10～14，SCLK3/SDI3连接板15～19。

### 电阻配置

- CS0～CS19分别使用4.7kΩ上拉到3.3V，确保FPGA复位或未配置时所有ADC均未选中。
- FPGA_SCLK和FPGA_SDI分别使用一个10kΩ下拉。
- 共享SDO在FPGA端使用一个10kΩ下拉，不在每块板上重复安装下拉。
- R21～R28为SCLK0～3和SDI0～3的串联电阻位，首版安装0Ω；若实测有过冲或振铃，可更换为10～22Ω。
- 现有ADS7953子板的SPI线上已经带有33Ω串联电阻。

### 控制和时序要求

- 初次联调建议SCLK不超过5MHz，波形确认后再提高到10MHz。
- 切换板卡时，先拉高当前CS并保持所有CS为高至少100ns，再拉低下一块板的CS。
- 切换过程中SCLK保持低电平，避免产生额外时钟边沿。
- 任何情况下不得同时拉低两路CS，否则多个ADS7953可能同时驱动共享SDO。

### 最新原理图审核结果

- 审核文件：`SCH_Schematic1_2026-09-07.pdf`，导出时间2026-09-07 20:38。
- J11电源脚隔离、公共地、74LVC244供电、4组SCLK/SDI扇出、20路独立CS及共享SDO连接均已核对通过。
- 进入PCB设计前，需要按20块板的最大总电流校核DC插座、开关、保险器件和5V电源走线宽度。
- 建议在开关后的5V总线增加100～470µF储能电容和1µF陶瓷电容，并预留保险丝或自恢复保险丝位置。
