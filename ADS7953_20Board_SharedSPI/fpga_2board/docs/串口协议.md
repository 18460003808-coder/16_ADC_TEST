# 两板验证工程串口协议

串口固定为 `115200 baud, 8 data bits, no parity, 1 stop bit`。上位机发送单字节 ASCII `T`（`0x54`）触发一次完整采集。FPGA 依次采集板 0 和板 1，然后发送两个 40 字节数据帧；两个帧的序号相同。

## 数据帧

| 偏移 | 长度 | 内容 |
|---:|---:|---|
| 0 | 1 | 帧头 `0xA5` |
| 1 | 1 | 帧头 `0x5A` |
| 2 | 1 | 协议版本，当前为 `0x01` |
| 3 | 1 | 板号：`0` 或 `1` |
| 4 | 1 | ADC 负载长度，固定为 `32` |
| 5 | 2 | 采集序号，小端序 |
| 7 | 32 | CH0～CH15，每通道 2 字节、小端序，仅低 12 位有效 |
| 39 | 1 | XOR 校验，覆盖偏移 2～38 |

每通道电压按 0～5 V 输入范围换算：

```text
millivolts = code × 5000 / 4095
```

本工程沿用 ADC 板接口到 ADS7953 通道的映射：

```text
IV0..IV15 -> CH14, CH12, CH10, CH8, CH13, CH15, CH9, CH11,
             CH5,  CH7,  CH1,  CH3, CH6,  CH4,  CH2, CH0
```

## 扩展到 20 块板

20 板版本继续使用此帧格式，板号扩展为 `0..19`。一次触发返回 20 个帧，所有帧使用同一采集序号，上位机收到该序号的全部 20 个板帧后再提交一组完整数据。
