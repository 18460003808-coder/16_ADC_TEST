# ADS7953 1～20板串口协议

串口参数为 `115200 baud, 8 data bits, no parity, 1 stop bit`。

- `43 NN`：ASCII `C`（`0x43`）后跟一个二进制数量字节`NN=1..20`，设置本次使用的板卡数量。
- `54`：ASCII `T`（`0x54`），触发一次采集。

FPGA上电默认使用20块板。配置为N块后，FPGA只扫描板0～板N-1并发送N个40字节帧；同一次触发产生的所有帧使用相同序号。旧上位机只发送`T`时仍保持原20板行为。

## 单板数据帧

| 偏移 | 长度 | 内容 |
|---:|---:|---|
| 0 | 1 | 帧头 `0xA5` |
| 1 | 1 | 帧头 `0x5A` |
| 2 | 1 | 协议版本 `0x01` |
| 3 | 1 | 板号 `0..19` |
| 4 | 1 | ADC负载长度，固定为 `32` |
| 5 | 2 | 采集序号，小端序 |
| 7 | 32 | CH0～CH15，每通道2字节、小端序，低12位有效 |
| 39 | 1 | XOR校验，覆盖偏移2～38 |

完整一组数据为 `N × 40` 字节。上位机必须按“采集序号+板号”归组，收到同一序号的板0～板N-1后才提交结果；重复板号覆盖该板旧帧，缺少任意所选板号均视为不完整。

## 通道与电压

```text
IV0..IV15 -> CH14, CH12, CH10, CH8, CH13, CH15, CH9, CH11,
             CH5,  CH7,  CH1,  CH3, CH6,  CH4,  CH2, CH0
```

Range 2、VREF=2.5 V时，理想LSB为 `5 V / 4096`：

```text
millivolts = code × 5000 / 4096
```

## 错误恢复

解析器持续搜索 `A5 5A`。版本、板号、负载长度或XOR校验不正确时丢弃当前候选帧并重新同步。FPGA忙于采集或发送上一组数据时忽略新的 `T`，避免两组数据交叠。板卡数量只在FPGA空闲时更新。
