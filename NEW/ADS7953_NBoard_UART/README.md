# ADS7953 N板UART工程

打开 `ADS7953_NBoard_UART.qpf`。SCLK/SDI/SDO由所有板共用，每块板使用独立CS。

板数在 `rtl/ads7953_board_count.vh` 中设置：

```verilog
`define ADS7953_BOARD_COUNT 1
```

允许范围1～20；板卡必须从板0连续安装到板N-1。修改宏后重新完整编译。

串口为115200/8-N-1；上位机发送`T`，FPGA返回N个数据帧和一个结束帧。详见 `docs/通信帧格式.md`。

每块板最多尝试32个SPI帧。缺板、SDO悬空或通道序列错误时，该板自动停止并清零本轮数据，控制器继续下一块板，不会拖死整轮采集。当前工作区顶层的`ADC_SCLK_HZ`为1 MHz；这是现有文件设置，本次未擅自改回旁边`.bak`中的10 MHz。

`host/dist/`内有主界面、全通道界面、示波器、FreeRun和读取诊断版EXE。它们根据结束帧动态采用实际板数，不需要在上位机写死N。五款上位机都读取CH0高字节bit7：主界面、FreeRun和Diagnostic把错误板16路标红；AllChannels把错误板对应的全局IV行标红；Scope用红色通道名和红色采样点标记错误。本轮状态同时写入Excel。需要重新生成时双击`host/一键生成上位机.cmd`。

AllChannels的Excel使用纵向通道、横向时间格式：A列固定为IV0～IV319，每次采集在右侧新增一列，列标题包含采集时间和Seq；错误板对应16个数据单元格标红，宏配置范围外的通道保持空白。若选择已有旧版横向工作簿，程序会保留旧表并新增“纵向通道数据”工作表。

`ADS7953_NBoard_FreeRun_UART.exe`是独立的固定周期触发版：默认每100 ms发送一次`T`、持续时间0表示一直发送，发送线程不等待FPGA反馈；接收、显示和导出仍在独立线程中工作。FPGA忙时收到的额外触发会被忽略，不会排队。

`sim/run.do`验证默认宏，`sim/run_20.do`验证20板配置。按需求，运行ModelSim前必须先取得用户许可。
