# ADS7953 N板UDP协议

## 网络参数

| 项目 | 默认值 |
|---|---|
| FPGA MAC | `02:00:00:00:79:53` |
| FPGA IPv4 | `192.168.1.50` |
| FPGA UDP端口 | `5000` |
| 上位机UDP端口 | `5001` |
| 物理接口 | RTL8211EG，1000BASE-T GMII |

上位机向广播地址 `192.168.1.255:5000` 发送一个ASCII字符 `T`。FPGA从收到的以太网帧中记录上位机的源MAC、源IP和源UDP端口，完成采集后直接向该地址回复，因此FPGA不需要ARP状态机。

## FPGA回复

每次采集只回复一个UDP数据报。UDP负载保持原N板串口版的应用层格式：

```text
板0数据帧(40B) + ... + 板N-1数据帧(40B) + 结束帧(8B)
```

总负载为 `N×40+8` 字节；20板时为808字节，小于标准以太网MTU。

### 数据帧

```text
A5 5A 01 板号 20 序号低 序号高 32字节ADC码 XOR
```

### 结束帧

```text
A5 5A 01 FF 板卡数量 序号低 序号高 XOR
```

UDP校验和为0（IPv4允许禁用UDP校验）；IPv4头校验和和Ethernet FCS由FPGA生成。
