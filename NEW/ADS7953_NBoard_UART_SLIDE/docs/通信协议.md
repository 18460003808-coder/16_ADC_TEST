# ADS7953 N板串口协议

串口参数：`115200 baud, 8-N-1`。上位机发送ASCII `T`（`0x54`）触发一次采集。

FPGA按照编译宏 `ADS7953_BOARD_COUNT=N` 依次扫描板0～板N-1，发送N个40字节数据帧，最后发送一个8字节结束帧。同一轮数据帧和结束帧使用相同采集序号。

## 数据帧（40字节）

| 偏移 | 长度 | 内容 |
|---:|---:|---|
| 0 | 2 | 帧头 `A5 5A` |
| 2 | 1 | 协议版本 `01` |
| 3 | 1 | 板号 `00..13`（十六进制，即0～19） |
| 4 | 1 | ADC负载长度 `20`（十六进制，即32字节） |
| 5 | 2 | 采集序号，小端序 |
| 7 | 32 | CH0～CH15，每通道2字节、小端序、低12位有效 |
| 39 | 1 | 偏移2～38的XOR校验 |

偏移8（CH0高字节）的bit7为本工程的板级SPI读取错误标志：`0=正常`，`1=达到32个SPI字仍未获得完整CH0～CH15`。错误时本板16路数据均应视为无效。ADC原码仍按`低字节 | ((高字节 & 0x0F) << 8)`解析；全通道滑轨上位机读取bit7并将错误板对应数据标红。

## 结束帧（8字节）

| 偏移 | 长度 | 内容 |
|---:|---:|---|
| 0 | 2 | 帧头 `A5 5A` |
| 2 | 1 | 协议版本 `01` |
| 3 | 1 | 结束标志 `FF` |
| 4 | 1 | 本工程实际板卡数量 `01..14`（十六进制，即1～20） |
| 5 | 2 | 采集序号，小端序 |
| 7 | 1 | 偏移2～6的XOR校验 |

结束帧使上位机无需预先配置板数，也不需要依赖串口空闲超时判断一轮数据何时完成。若结束帧报告N块，但缺少板0～板N-1中的任何数据帧，上位机将显示缺失板号，不提交该轮数据。

## 滑轨移动命令（7字节）

此命令只用于SLIDE工程，不改变原有`T`触发、40字节数据帧和8字节结束帧。

| 偏移 | 内容 |
|---:|---|
| 0 | `55` |
| 1 | `AA` |
| 2 | 命令字`4D` |
| 3 | 方向：`01`正向，`00`反向 |
| 4 | PWM脉冲数低字节 |
| 5 | PWM脉冲数高字节 |
| 6 | Byte2～Byte5的XOR |

正向移动1 mm即80个脉冲，命令为：

```text
55 AA 4D 01 50 00 1C
```

FPGA仅在滑轨空闲、ADC采集空闲、ADC数据帧未在组包且校验正确时接受命令。方向和脉冲数在启动时锁存。未满足条件的命令不会排队，上位机会因收不到匹配的完成帧而超时停止。

## 滑轨完成帧（9字节）

FPGA完成最后一个PWM后发送：

| 偏移 | 内容 |
|---:|---|
| 0～1 | 帧头`A5 5A` |
| 2 | 版本`01` |
| 3 | 滑轨帧标志`FE` |
| 4 | 状态`01`，表示运动完成 |
| 5 | 实际方向`00/01` |
| 6～7 | 本次脉冲数，小端序 |
| 8 | Byte2～Byte7的XOR |

正向80个脉冲完成帧为：

```text
A5 5A 01 FE 01 01 50 00 AF
```

上位机从发送命令起显示红灯，只在收到方向、脉冲数和XOR均匹配的完成帧后显示绿灯并进入下一步。
