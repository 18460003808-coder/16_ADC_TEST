# ADS7953与滑轨联动使用说明

## 1. 下载与连接

1. 用Quartus打开`ADS7953_NBoard_UART_SLIDE.qpf`。
2. 确认`rtl/ads7953_board_count.vh`中的板数与实际要扫描的连续板号范围一致。
3. 完整编译并下载`output_files/ADS7953_NBoard_UART_SLIDE.sof`。
4. FPGA的PIN_A20连接滑轨驱动器脉冲输入，PIN_A19连接方向输入，并确保两者共地。
5. 打开`host/dist/ADS7953_NBoard_AllChannels_UART_SLIDE.exe`，选择FPGA串口并连接。

## 2. 单独测试滑轨

1. 先选0.5 mm，选择正向并点击“滑动”。
2. 状态灯应立即变红；40个2 kHz脉冲结束、FPGA返回完成帧后变绿。
3. 再选择反向0.5 mm，确认滑轨回到原位。
4. 若方向相反，应检查驱动器方向定义或交换界面方向；不要通过改变脉冲数修正方向。

单独调试允许0.5～300 mm；ADC联动的单步距离仍限制为0.5～2 mm。

换算关系：

```text
脉冲数 = 距离(mm) × 80
0.5 mm = 40脉冲，约20 ms
1.0 mm = 80脉冲，约40 ms
2.0 mm = 160脉冲，约80 ms
300 mm = 24000脉冲，约12 s（仅单独调试）
```

## 3. 联动采集

1. 设置每步距离0.5～2 mm。
2. 设置采集间隔500～5000 ms。该值是相邻两次采集启动之间的最小时间；如果滑轨尚未完成，则实际间隔自动延长。
3. 设置移动次数N并点击“开始联动”。
4. 滑轨完成反向复位后，程序弹出“另存为”，输入本次文件名并保存。

位置顺序如下：

```text
位置0采集 → 正向1步
位置1采集 → 正向1步
...
位置N-1采集 → 正向1步
反向复位N步 → 导出N列数据
```

因此N表示N次采集和N次正向移动。每次联动都会新建独立Excel，不会追加以前的联动文件。Excel的A列固定为IV0～IV319，右侧每一列是一轮采集，标题包含真实采集时间、Seq和该轮位置。错误板对应的16个数据单元格保持红色。

如果在“另存为”窗口点击取消，本次数据仍保存在程序内存中，联动按钮会变为“保存联动数据”；点击后可以再次命名。保存成功前不能开始下一次联动。

## 4. 异常处理

- 红灯长时间不变：检查UART是否仍连接、SOF是否为SLIDE版本、A19/A20是否接到驱动器正确端子。
- ADC采集超时：联动会停止。此前可能已经移动若干步，程序不会在位置不确定时自动继续；确认机械位置后使用单独调试反向复位。
- Excel导出失败：常见原因是选择的同名文件正被Excel占用。数据仍保留在内存中，关闭占用文件后点击“保存联动数据”重试。
- 不要在联动运行期间使用其他串口工具向同一COM口发送数据。

## 5. 示波器检查

检查PIN_A20时，探头地接系统地，触发选择上升沿。2 kHz PWM周期应为500 us，高、低电平各约250 us。正向运动期间PIN_A19应为高，反向复位期间应为低；方向信号在整段PWM输出期间必须保持稳定。

## 6. 320×N灰度成像

1. 在“320×N灰度成像”区域点击“选择Excel”，可选择以前保存的纵向采集表格。
2. 联动或普通采集刚生成Excel后，该文件会自动成为当前灰度数据源，无需再次选择。
3. 设置黑色对应的最小电压，默认0 V；设置白色对应的最大电压，默认5 V。最大值必须大于最小值。
4. 点击“生成灰度图”，程序先显示放大预览，不会自动保存文件。
5. 需要保存时点击预览窗口中的“导出PNG”，再选择文件名和位置；只想查看时直接关闭预览即可。

Excel读取和灰度计算在后台线程执行，状态栏会显示“正在后台读取Excel并计算”，此时窗口仍可移动和刷新。完成后直接弹出预览；PNG保存窗口只在用户点击“导出PNG”后出现。

图像纵向从上到下对应IV0～IV319，横向从左到右对应第1～第N次采集。Excel中的毫伏值会转换成伏特后映射：小于等于最小电压为黑，大于等于最大电压为白，中间值按线性比例生成灰度。未配置或空白通道按最小值显示为黑色。

输入Excel必须采用本上位机的纵向格式：A列第2～321行依次为IV0～IV319，B列开始为各次采集数据。输出PNG的原始像素尺寸为N×320；预览窗口仅进行最近邻放大，不改变保存图片的原始数据。
