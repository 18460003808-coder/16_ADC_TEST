# ADS7953子板与采集卡插口映射配置说明

## 1. 作用

FPGA数据帧中的`Board`表示采集卡物理插口，不一定等于实际子板编号。两个上位机启动时读取EXE同目录下的`board_mapping.csv`，把物理板号转换成逻辑子板号，再进行显示、标红、波形和Excel导出。

该功能同时适用于：

- `ADS7953_NBoard_AllChannels_UART_SLIDE.exe`
- `ADS7953_NBoard_Scope_UART.exe`

FPGA RTL、UART帧和每块板内部的ADC通道到IV接口映射均未改变。

## 2. 文件格式

配置文件必须命名为`board_mapping.csv`并放在EXE旁边，固定包含20行映射：

```csv
capture_slot,logical_board
1,1
2,2
3,3
...
20,20
```

两个编号都使用便于人工核对的1～20：

- `capture_slot`：采集卡物理插口编号。
- `logical_board`：这个插口实际连接的子板编号。

上位机内部仍使用0～19板号，因此逻辑子板1对应全局`IV0～IV15`，逻辑子板2对应`IV16～IV31`，以此类推。

## 3. 交换插口示例

如果实际子板1插在采集卡插口2，实际子板2插在采集卡插口1，配置为：

```csv
capture_slot,logical_board
1,2
2,1
3,3
4,4
...
20,20
```

此时：

```text
FPGA物理Board 0（插口1） -> 逻辑子板2 -> IV16～IV31
FPGA物理Board 1（插口2） -> 逻辑子板1 -> IV0～IV15
```

## 4. 生效范围

映射在一轮物理数据帧收齐后统一执行，随后影响：

- AllChannels页面的IV0～IV319显示顺序。
- Scope的通道名称、曲线和通道选择。
- SPI异常板的红色标记位置。
- 普通采集、连续采集和滑轨联动数据。
- AllChannels纵向Excel和Scope Excel。
- 由映射后Excel生成的320×N灰度图。

错误标志会与该物理板的16路数据一起映射。例如插口2读取失败且它配置为逻辑子板1，最终标红的是IV0～IV15。

## 5. 配置校验

启动时上位机会检查：

- 文件是否存在。
- 表头是否包含`capture_slot`和`logical_board`。
- 两列是否都是1～20的整数。
- 20个采集卡插口是否全部配置且没有重复。
- 20块逻辑子板是否全部配置且没有重复。

配置缺失或错误时，上位机会显示错误并禁止连接串口，避免使用错误的通道对应关系继续采集。

## 6. 修改步骤

1. 关闭两个上位机。
2. 用文本编辑器或Excel打开EXE旁的`board_mapping.csv`。
3. 按实际接线修改每个`capture_slot`对应的`logical_board`。
4. 保存为CSV格式，不要修改两列表头。
5. 重新启动上位机；启动状态应显示“已加载板卡映射：board_mapping.csv”。
6. 建议先交换两块板进行小范围验证，确认AllChannels显示、Scope曲线和Excel行号一致后再投入完整采集。

配置只在程序启动时读取。运行期间修改CSV不会立即生效，必须重新启动上位机。

## 7. 板数少于20时

配置文件仍保留完整20行。上位机只映射本轮结束帧声明的物理插口范围；逻辑编号可以不连续：

- AllChannels只显示实际收到的逻辑子板数据，纵向Excel仍固定保留IV0～IV319，未收到的逻辑子板保持空白。
- Scope通道列表扩展到本轮最高逻辑IV号，中间未收到的逻辑子板没有采样数据。

FPGA能采到哪些物理插口仍由`ADS7953_BOARD_COUNT`宏决定；上位机映射不能读取FPGA未扫描的物理插口。
