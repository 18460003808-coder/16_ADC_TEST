# ADS7953板卡序号与板内接口映射配置说明

## 1. 两类映射

AllChannels和Scope两款上位机共同使用两类映射：

1. 板卡序号映射：把FPGA数据帧中的采集卡物理插口转换为实际逻辑子板编号。
2. 板内接口映射：把每块子板的`IV0～IV15`转换为ADC原始`CH0～CH15`。

映射只改变上位机如何解释、显示和导出收到的数据，不修改FPGA RTL、UART通信帧、ADS7953扫描顺序或SOF。

两款上位机共用同一组配置，因此AllChannels显示、Scope曲线、错误标红、普通/联动Excel和灰度图中的全局`IV0～IV319`保持一致。

## 2. 直接在上位机中修改

1. 如果已经连接串口，先点击“断开”。
2. 点击主界面顶部的“映射配置”。
3. 左侧设置“采集卡物理插口 → 实际逻辑子板”。
4. 右侧设置“板内接口 → ADC通道”。
5. 点击“保存并应用”。

保存时会检查两组映射都是一一对应关系。保存成功后CSV立即更新并在当前程序中生效，不需要重新启动；为避免新旧映射数据混合，当前显示数据和Scope历史波形会清空。串口连接或采集期间不允许修改。

如果CSV缺失或内容错误，上位机会禁止连接，但仍可打开“映射配置”，使用界面重新保存一套有效配置进行修复。

## 3. 板卡序号映射文件

文件名：`board_mapping.csv`

```csv
capture_slot,logical_board
1,1
2,2
3,3
...
20,20
```

- `capture_slot`：采集卡物理插口，使用1～20。
- `logical_board`：实际子板编号，使用1～20。
- 20个物理插口和20个逻辑子板都必须各出现一次。

例如实际子板1插在采集卡插口2、实际子板2插在插口1：

```csv
capture_slot,logical_board
1,2
2,1
3,3
...
20,20
```

此时FPGA物理Board 0显示为逻辑子板2的`IV16～IV31`，FPGA物理Board 1显示为逻辑子板1的`IV0～IV15`。读取错误标志会随同该物理板的16路数据一起映射。

## 4. 板内接口映射文件

文件名：`channel_mapping.csv`

```csv
local_iv,adc_channel
0,14
1,12
2,10
3,8
4,13
5,15
6,9
7,11
8,5
9,7
10,1
11,3
12,6
13,4
14,2
15,0
```

- `local_iv`：每块子板上的接口编号0～15。
- `adc_channel`：ADS7953原始通道号0～15。
- IV0～IV15和ADC CH0～CH15都必须各出现一次。
- 当前20块子板共用这一套板内映射，不为每块板分别配置。

例如把`local_iv=0`配置为`adc_channel=3`后，每块逻辑子板的第一个接口都会读取该板ADC CH3：逻辑子板1的全局IV0、逻辑子板2的全局IV16，以此类推。

## 5. 配置文件位置

Windows正式EXE从EXE同目录读取和保存：

```text
board_mapping.csv
channel_mapping.csv
```

macOS两款应用共用：

```text
~/Library/Application Support/ADS7953_NBoard_UART_SLIDE/board_mapping.csv
~/Library/Application Support/ADS7953_NBoard_UART_SLIDE/channel_mapping.csv
```

Mac首次启动会自动生成当前默认映射。通常不需要手工打开CSV，直接使用上位机中的“映射配置”即可。

## 6. 生效范围

两类映射共同影响：

- AllChannels页面的IV0～IV319显示及ADC通道列。
- Scope通道选择、实时曲线和Excel。
- SPI异常板对应的红色标记位置。
- 普通采集、连续采集和滑轨联动Excel。
- 由纵向Excel生成的320×N灰度图。

原始UART帧仍始终保存ADC CH0～CH15，映射不会写回FPGA。

## 7. 板数少于20时

`board_mapping.csv`仍保留完整20行。上位机只映射本轮结束帧声明的物理插口范围，逻辑子板编号可以不连续：

- AllChannels只显示实际收到的逻辑子板，纵向Excel仍固定保留IV0～IV319，未收到的逻辑子板为空白。
- Scope通道列表扩展到本轮最高逻辑IV号，中间未收到的逻辑子板没有采样数据。

FPGA扫描哪些物理插口仍由`ADS7953_BOARD_COUNT`宏决定；上位机映射不能读取FPGA没有扫描的插口。
